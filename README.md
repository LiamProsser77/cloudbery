# About

Cloudbery is an open-source social platform where users can upload videos, discover content, and interact with videos shared by the community.

# Features

- User registration and sign-in
- Public video feed
- Video uploads
- Like and unlike videos
- Delete your own videos
- Search videos by title or creator
- Random video discovery
- Automatic video playback while scrolling
- User profiles

# Technologies

- HTML
- CSS
- JavaScript
- Supabase Authentication
- Supabase Database
- Supabase Storage

# How It Works

Cloudbery uses Supabase to handle user accounts, video information, likes, and video storage.

Users can upload videos, which are stored in Supabase Storage. Video titles and information are saved in the database and displayed in the public feed.

# Installation

Clone the repository:

    git clone https://github.com/LiamProsser77/cloudbery.git

Open the project folder and configure your Supabase project in `supabase.js`.

Set up the required database tables, storage buckets, and security policies.

Open `index.html` or deploy the project using GitHub Pages.
